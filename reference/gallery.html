composed-02 — Slide-in detail panel (from the right)

Standard detail behavior for tables, cards and list items: the panel opens ONLY from an explicit action (eye icon, kebab menu item, "View" button) — NEVER from clicking the row/card itself. Fixed header + fixed footer, exactly ONE scrolling body. Shown here in its open state.

Page content stays visible (and inert) behind the panel. The panel never replaces the page — closing it returns the user exactly where they were.
