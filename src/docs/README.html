npm error ERESOLVE? Itu konflik dependency lama bawaan repo (bukan dari design system). Installer otomatis retry dengan --legacy-peer-deps. Kalau install manual: npm i -D @iconify/tailwind @iconify-json/tabler --legacy-peer-deps. Fix permanen: buat .npmrc di root repo berisi legacy-peer-deps=true.npm error ERESOLVE? A pre-existing dependency conflict inside the repo (not from the design system). The installer auto-retries with --legacy-peer-deps. Manual install: npm i -D @iconify/tailwind @iconify-json/tabler --legacy-peer-deps. Permanent fix: add a .npmrc at the repo root containing legacy-peer-deps=true.
